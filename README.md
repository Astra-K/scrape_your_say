# 📝 Scrape Your Say — EU Consultation Data Analysis
This repository provides tools to analyze public consultation feedback from the European Commission's **"Have Your Say"** initiative. It processes structured YAML data on consultation topics, respondent categories, and geographic distributions, and produces normalised statistics and visualisations.

## 🔧 Setup

### 1. Clone the Repository
git clone https://github.com/Astra-K/scrape_your_say.git
cd scrape-your-say
pip install -r requirements.txt
Make sure the input YAML file is placed in the data/ folder. Then, run the analysis script.

## ▶️ Running the Analysis
python src/scrape_analysis.py
You can generate your own current Yaml using https://github.com/Mia-Deutsch/scrape_your_say this webscrapper.
